# Quantitative Trading with R 中文翻译项目

本目录仅保存 Harry Georgakopoulos 所著 *Quantitative Trading with R: Understanding Mathematical and Computational Tools from a Quant's Perspective* 的中文翻译项目资料，不包含新书 *Quantitative Trading with R and Python* 的 Python 扩展稿或构建文件。

在线阅读：<https://dengyishuo.github.io/quantitative-trading-with-r/>

## 目录结构

- `docx/量化金融与R语言_初稿_0711V1.docx`：中文翻译 Word 草稿。
- `reference/Quantitative-Trading-with-R.pdf`：英文原书，仅用于翻译核对。
- `code/`：按章节整理的原书 R/C++ 配套代码。
- `data/`：原书示例数据及外部数据说明。

公开仓库仅发布 `docs/`、`code/`、`data/` 和本 README；Word 草稿与英文原书 PDF 仅保留在本地。

原书及其内容的著作权归作者和出版方所有。本目录仅用于学习、研究和翻译整理，请勿用于商业用途或公开传播。
