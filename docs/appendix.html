第2章

  1. 编程范式是由数学衍生来的一系列概念，其目的是找出针对某一个问题的高效优雅的解决方案。例如，对于能够分解为层次交互对象的问题，适合用面向对象编程[85,137]来处理。而函数式编程则适合涉及数据处理、操作和转换的问题。函数式编程的产生基于由Alonzo Church于1936年提出的λ-积分概念。函数式编程是编程范式的基石。其核心观点是创造出某种函数，使得该函数的输出仅依赖于函数的输入，但这些函数不允许对外部数据进行操作。

  2. 如果编程语言可以用以模拟任何单片图灵机，则其是图灵完备的。单片图灵机是一种可以模拟任何基于有限内存计算机的机械装置。下面的链接给出了一份关于图灵机的介绍：http://en.wikipedia.org/wiki/Turing machine。从实用角度而言，如果某种编程语言是图灵完备的，那么只要拥有足够多的资源，它就可以计算所有可计算的问题。

  3. 编译是指将人类可读代码转换为机器代码的过程。编译过的代码运行速度快，但缺点是编译过程十分耗时。一种替代操作方案是让计算机把人类可读代码转换为更具操作性的对象。这种操作方式便于开发者与代码之间的高效交互，缺点是代码运行速度较慢。

  4. Julia是一门相对较新的编程语言，但它在科学编程领域已经显现出巨大的潜力。它的基于LLVM的即时编译机制使得它被应用于大多数数值计算应用时运算速度极快（可以跟C语言媲美）。更多关于该语言的细节可以点击如下链接：http://julialang.org/。

  5. 参考语法意味着变量不再存储对象的数值，而是存储对象在内存中的物理位置。这种处理方式可以提升代码效率，因为庞大的对象在传递过程中无需被拷贝。

  4. 过拟合是这样一种情况，拟合模型的输出结果是完全错误的或者完全不具备预测能力。通常很难发现模型拟是否过拟合，尤其在高维模型中更是如此。因此，在拟合数据模型过程中要特别小心。正则化方法以及收缩方法可以在一定程度上限制过拟合的发生。
